## Historical experiment reproduction

Use the original working Python environment where possible. The recorded
environment includes Windows 11, Python 3.10.11, NumPy 1.26.4, and Matplotlib
3.10.1. `requirements.txt` lists the packages used by the source; it is not a
complete environment lockfile. PyTorch and PyTorch Geometric are required by
the full executable model. The original exact versions of every dependency
are not recorded in the supplied material.

For a fresh environment, install the requirements before running the model:

```powershell
python -m pip install -r requirements.txt
```

From this directory in the VS Code PowerShell terminal, the full reproduction
command is:

```powershell
python compare_decentralized_centralized.py `
  --T 1000 --nsim 20 `
  --seed-root 42 --seed-namespace FORMAL `
  --stop-alive-threshold 1 `
  --den-matcher-mode load --cen-matcher-mode off `
  --all-scenarios --force-rerun
```

This explicitly reruns the four rollover/support configurations and the
separate loan-cap sweep. The formal configurations use the named FORMAL
seed stream. The loan-cap routine uses its own 20-seed sample as recorded in
the manifest, so its B=1200 cell is a separate replication of the parameter
setting. Outputs are written under `输出/figures/` next to these source files.
The source fingerprint must match when reusing old artifacts.

The existing complete output archive is the user's `figures.zip`; retain its
directory structure under `输出/figures/` for reuse. To regenerate the existing
comparison program's plots without rerunning simulation, replace
`--force-rerun` in the command above with `--skip-run`.

The thesis revision's three replacement figures are generated by
`../../scripts/rebuild_review_figures.py`, not by modifying this historical
simulation snapshot. Run that script from the thesis root as described in
the root README; it reads the supplied compact plotting inputs and requires
NumPy and Matplotlib only.

## Verification and repository version

`../../scripts/verify_reproduction.py` checks the byte-level source identity,
the two original negative-equity cascade methods with a controlled contract
fixture, the original shared estate resolver, and the initial-state CSV.
Its optional `--artifacts-dir` checks all 14 raw artifact files against the
manifest. These are targeted checks, not a full simulation regression run.
